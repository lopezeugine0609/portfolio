# Eugine Lopez – DevOps & Automation Portfolio

Modern, lightweight, responsive engineering portfolio highlighting hands-on systems work in DevOps, cloud infrastructure, AI integrations, and self-hosted n8n workflow automation.

## 🚀 Featured Systems & Automation Builds

- **Meeting Audio Intelligence & CRM Router**: End-to-end meeting recording pipeline using self-hosted n8n, AssemblyAI speaker diarization polling, OpenAI GPT structured outcome extraction, and automated HubSpot/Google Calendar synchronization.
- **Automated Opportunity Lead Review Pipeline**: Scheduled sourcing engine querying remote contract APIs with a 45-day rolling deduplication state store and automated outreach note drafting.
- **Candidate Submission & Triage Automation**: Recruitment funnel verifying resumes and video introductions (Loom links) with automated CRM pipeline stage routing.
- **Customer Renewal Reminder System**: Subscription lifecycle tracker in n8n with date evaluation math, high-value contract routing, and VIP Slack alerts.
- **Weekly Operations & KPI Reporting**: Business intelligence pipeline calculating Week-over-Week (WoW) performance deltas and broadcasting formatted Markdown briefs to team chat.

## 🛠️ Tech Stack

- **Core**: Semantic HTML5, CSS3 Variables, Vanilla JavaScript (Zero external runtime dependencies).
- **Automation & APIs**: Self-hosted n8n, Docker Compose, REST APIs, Webhooks.
- **Deployment**: Vercel Static Hosting (`vercel.json`).
